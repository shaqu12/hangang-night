# 밤 한강 돗자리

밤 한강 강변에 돗자리가 깔려 있고, **지금 접속한 사람마다 캐릭터가 하나씩** 산책로로 걸어 들어온다. 들어온 사람은 빛나는 빈 돗자리를 눌러 직접 골라 앉고, 앉은 뒤에도 다른 빈자리를 눌러 옮길 수 있다. 같은 자리를 동시에 누르면 서버에 먼저 도착한 사람이 앉고, 늦은 사람에게는 "방금 다른 분이 먼저 앉았어요"가 뜬다. 나가면 일어나서 걸어 나간다. NPC 없음, 채팅 없음, 이모지 6개(🌙 ✨ 🍜 👋 💤 ❤️)만.

- 파일: `server.js`(실시간 서버, 약 4KB) + `index.html`(화면·소리, 약 25KB). 외부 라이브러리는 `ws` 하나. AI·음원·이미지 파일 없음.
- 방: 한 방에 돗자리 30개. 차면 다음 방(여의도 01 → 반포 01 → 뚝섬 01 …), 최대 20방 600명.
- 남용 방지: IP당 동시 접속 4개, 이모지 1.2초에 1번, 자리 옮기기 0.6초에 1번, 메시지 256바이트 제한, 30초 무응답 연결 정리.

## 화면
- 하늘: 반짝이는 별, 달(달무리·무늬), 천천히 흐르는 옅은 구름, 도시 불빛이 번진 지평선.
- 건너편: 스카이라인 3겹(먼 줄은 옅게, 가까운 줄은 진하게), 남산과 N타워(꼭대기 불빛 깜박임), 금빛 유리 빌딩, 항공 경고등, 강변북로 가로등 줄과 오가는 차 불빛.
- 강: 도시가 물에 거꾸로 비쳐 가로줄마다 물결처럼 일렁임, 달빛 길, 강 위 옅은 안개.
- 아치 다리: 교각 사이 아치 조명이 물에 비쳐 동그라미처럼 보임, 상판 조명은 파랑~보라로 천천히 바뀜, 25~55초마다 지하철이 건넘.
- 유람선: 50~100초마다 2층 선실 불빛·줄전구를 켜고 지나가며 물결 자국과 반영을 남김.
- 캐릭터: 뒤에서 본 2등신(후드티 색 10가지, 머리색 5가지). 내 캐릭터 위에는 화살표와 "나".

## 소리
실제 녹음 파일 `ambience.mp3`(저장소 맨 위)를 반복 재생한다. 파일이 없으면 소리 버튼이 숨겨지고 조용히 동작한다.
코드로 합성한 소리(바람·물소리·싱잉볼)는 "작위적"이라 모두 뺐다.

- 원하는 분위기: 강가 밤 공기, 아주 잔잔한 물결, 멀리서 웅웅대는 차 소리, 멀리서 희미한 사람들 말소리, 약한 풀벌레. 음악·종소리·강한 바람 없음.
- 편집: 이음새 없이 반복되도록 끝 4초를 앞에 겹치고, 작게(-30 LUFS 안팎) 만들어 1~3MB 이내로.
- 출처·라이선스: (녹음을 정하면 여기에 적는다. 상업적 이용 가능한 것만, CC0 우선)

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```
혼자 여러 창으로 시험할 때는 `PER_IP=50 npm start` (IP당 4개 제한을 풀어 줌).

## 주소
- `/` 화면, `/ws` 웹소켓, `/health` 상태 확인, `/stats` 접속자 수(JSON)

## 서버가 보내는 메시지
`init`(내 id, 방 번호, 지금 앉아 있는 사람들) · `join` · `leave` · `emo` · `count` · `full`
