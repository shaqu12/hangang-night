# 밤 한강 돗자리

밤 한강 강변에 돗자리가 깔려 있고, **지금 접속한 사람마다 캐릭터가 하나씩** 산책로로 걸어 들어온다. 들어온 사람은 빛나는 빈 돗자리를 눌러 직접 골라 앉고, 앉은 뒤에도 다른 빈자리를 눌러 옮길 수 있다. 같은 자리를 동시에 누르면 서버에 먼저 도착한 사람이 앉고, 늦은 사람에게는 "방금 다른 분이 먼저 앉았어요"가 뜬다. 나가면 일어나서 걸어 나간다. NPC 없음, 채팅 없음, 이모지 6개(🌙 ✨ 🍜 👋 💤 ❤️)와 돗자리 위 행동 8가지만.

**행동(화면 아래 줄)**: 🧘 앉기 · 🛌 눕기 · 🌟 별 보기 · 🍜 라면 · 🍗 치킨 · 📸 사진 · 🙆 기지개 · 😪 꾸벅. 누르면 같은 방 모두에게 내 캐릭터가 그 자세로 보이고, 같은 버튼을 다시 누르면 앉기로 돌아온다. **폭죽(🎆)**: 버튼을 누르고 화면을 아래로 당겼다 놓으면 내 캐릭터 자리에서 폭죽이 솟아 야경 위에서 터지고 강물에 비친다. 당긴 길이로 높이·크기가 정해지고, 모양(국화·고리·버들·겹꽃·하트)과 색 7가지는 서버가 무작위로 정해 같은 방 모두에게 똑같이 보인다. 한 사람당 2.5초에 1발, 화면 전체 불꽃 알갱이는 900개까지(한 발 36~80개), 소리는 올라갈 때 '삐슈우웅'(음이 올라가는 휘파람), 터질 때 '펑' + 0.33초 메아리·2.6초 잔향·타다닥. 기본 크기에서 약 -23 LUFS(배경 강물 -48 LUFS보다 25dB 큼), 압축기로 꼭대기 -4.8dBFS 아래로 눌러 깨짐 방지, 소리 패널 전체 크기를 따름. 오늘 쏜 수는 그 기기에 저장된다. 이모지는 맨 왼쪽 😊 버튼 안에 있고, 👋를 보내면 캐릭터가 손도 흔든다. 그림은 기존 캔버스에 선 몇 개를 더 그리는 정도라 폰 부담이 거의 늘지 않는다.

- 파일: `server.js`(실시간 서버, 약 4KB) + `index.html`(화면·소리, 약 25KB). 외부 라이브러리는 `ws` 하나. AI·음원·이미지 파일 없음.
- 방: 한 방에 돗자리 30개. 차면 다음 방(여의도 01 → 반포 01 → 뚝섬 01 …), 최대 20방 600명.
- 남용 방지: IP당 동시 접속 20개(통신사·학교 와이파이는 IP를 여럿이 같이 써서 넉넉히, 환경 변수 `PER_IP`로 변경), 이모지 1.2초에 1번, 자리 옮기기 0.6초에 1번, 행동 0.4초에 1번(정해진 8가지만 통과), 메시지 256바이트 제한, 30초 무응답 연결 정리.

## 화면
- 하늘: 남색 → 보라 → 지평선의 따뜻한 자주 그라데이션, 별 210개(40개는 반짝임), 25~60초마다 별똥별, 달, 옅은 구름, 가끔 비행기.
- 건너편: 스카이라인 3겹, 남산과 N타워, 금빛 유리 빌딩, 모서리·꼭대기에 천천히 색이 도는 LED 빌딩 3채, 18~68초 주기로 하나씩 켜지고 꺼지는 창문 최대 160개, 항공 경고등, 강변북로 차 불빛. 불빛 번짐(블룸).
- 강: 도시가 물에 거꾸로 비쳐 천천히 일렁임, LED 빌딩의 색 반사, 달빛 길, 옅은 안개.
- 다리와 달빛무지개분수: 70초 중 50초 동안 상판에서 무지개색 물줄기가 쏟아지고 색이 천천히 흐름, 물보라와 색 번짐, 물 위 반사. 25~55초마다 지하철.
- 유람선: 3층 선실 창문 불빛(조금씩 깜박임), 파란 선체 조명, 돛대에서 뱃머리·고물까지 5색 줄전구, 물에 세로로 길게 늘어지는 반사, 초당 9U로 아주 천천히(화면을 건너는 데 1분 안팎).
- 돗자리: 그림자, 가장자리 박음질, 접힌 자국, 앞쪽 그늘. 빈자리는 은은하게 빛남.
- 캐릭터: 뒤에서 본 2등신, 머리 모양 5가지, 테두리 빛, 소품(컵라면·캔·랜턴·휴대폰 불빛).
- 가장자리를 살짝 어둡게(비네트). 세로 화면은 돗자리 5줄×6, 가로 화면은 3줄×10.

## 소리
실제 녹음 3개를 섞지 않고 **따로** 반복 재생한다. 오른쪽 위 🔊를 누르면 전체 크기와 강물·도시·풀벌레를 각각 켜고 끄고 크기를 고를 수 있다(설정은 그 기기에 저장). 기본은 강물만 켜짐. 파일은 켠 것만 내려받는다.

| 파일 | 녹음 (Pixabay 파일 이름) | 쓴 구간 | 파일 크기 | 기본 |
|---|---|---|---|---|
| `amb-river.mp3` | distant-river-at-night | 80~236초 | 1.2MB | 켜짐, 60 |
| `amb-city.mp3` | quiet-city-square-night | 470~626초 (645~690초의 큰 소리 구간은 피함) | 1.2MB | 꺼짐, 35 |
| `amb-crick.mp3` | night-tree-crickets-distant-traffic | 14~170초 | 1.2MB | 꺼짐, 35 |

- 편집: 60Hz 아래를 깎고 각각 -24 LUFS로 맞춘 뒤, 끝 6초를 앞 6초에 등전력 크로스페이드로 겹쳐 150초 동안 이음새 없이 반복. 64kbps 스테레오 mp3.
- 크기: Web Audio 게인으로 조절(아이폰은 audio.volume을 무시함). 슬라이더 값 v는 (v/100)²배. 기본값(전체 60 × 강물 60)이면 약 **-48 LUFS**. 일반 음악(약 -14 LUFS)보다 34dB 작다.
- 강물 다듬기: 원본 강물 녹음은 200~1500Hz가 고르게 깔린 "쏴아" 소리(14분 동안 크기 변화 0.5dB)라 폰에서 바람 "휘이익"처럼 들렸다. 800Hz 위를 잘라(800Hz 위 에너지 33% → 2%) 멀리서 웅웅 흐르는 물소리로 만들고, 8초·5초 주기로 ±2dB만 천천히 커졌다 작아지게 해 물결 느낌을 냈다. 파일 자체도 4.9dB 작게.
- 섞었을 때 별로였던 이유: 도시 녹음은 에너지의 92%가 200Hz 아래(먼 차 웅웅)라 강물 위에 겹치면 탁해지고, 풀벌레 녹음은 2.36kHz 울음이 주변보다 17dB 튀어서 셋 중 가장 귀에 걸린다. 도시·강물 녹음에는 풀벌레가 거의 없다.
- 출처·라이선스: [Pixabay](https://pixabay.com/sound-effects/) 효과음, [Pixabay Content License](https://pixabay.com/service/license-summary/). 상업적 이용이 가능하고 출처 표기는 필요 없다. 다만 음원 파일 자체만 따로 재배포하거나 판매하는 건 금지다(이 앱의 배경음으로 쓰는 건 괜찮다).
- 코드로 합성한 소리(바람·물소리·싱잉볼)는 "작위적"이라 모두 뺐다.

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```
혼자 여러 창으로 시험할 때는 `PER_IP=50 npm start` (IP당 4개 제한을 풀어 줌).

## 주소
- `/` 화면, `/ws` 웹소켓, `/health` 상태 확인, `/og.jpg` 링크 미리보기 이미지
- `/stats` 지금 접속자 수 + 오늘·어제 방문(횟수, 사람 수, 머문 시간 평균·가운데 값, 5분 이상, 동시 최고, `?from=` 출처별). 메모리에만 있어 재시작하면 0부터, 매시 정각 Render 로그에 `[stats]`로 남김. IP는 하루짜리 해시로만 씀.
- 공유 방법은 `공유-홍보-가이드.md`
