# 밤 한강 돗자리

밤 한강 강변에 돗자리가 깔려 있고, **지금 접속한 사람마다 캐릭터가 하나씩** 산책로에서 걸어 들어와 빈 돗자리에 앉는다. 나가면 일어나서 걸어 나간다. NPC 없음, 채팅 없음, 이모지 6개(🌙 ✨ 🍜 👋 💤 ❤️)만.

- 파일: `server.js`(실시간 서버, 약 4KB) + `index.html`(화면·소리, 약 25KB). 외부 라이브러리는 `ws` 하나. AI·음원·이미지 파일 없음.
- 방: 한 방에 돗자리 30개. 차면 다음 방(여의도 01 → 반포 01 → 뚝섬 01 …), 최대 20방 600명.
- 남용 방지: IP당 동시 접속 4개, 이모지 1.2초에 1번, 메시지 256바이트 제한, 30초 무응답 연결 정리.

## 화면
야경(남산타워·건너편 건물 불빛), 색이 천천히 바뀌는 다리 조명, 25~55초마다 다리를 건너는 지하철, 50~100초마다 지나가는 유람선, 물 위 반짝임. 캐릭터는 뒤에서 본 2등신(후드티 색 10가지, 머리색 5가지), 앉아 있으면 숨 쉬듯 살짝 움직인다. 내 캐릭터 위에는 화살표, 처음 8초는 "나" 표시.

## 소리
음원 없이 브라우저가 32초짜리 고리를 계산(폰 1~2초): 0.4~1.3초 간격 강물 찰랑임 + 16초 주기로 커졌다 작아지는 바람 + 아주 낮은 도시 웅웅. 끝 4초를 앞에 겹쳐 이음매가 없다. `<audio>`로 틀어서 폰 화면을 꺼도 계속 나온다.

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```
혼자 여러 창으로 시험할 때는 `PER_IP=50 npm start` (IP당 4개 제한을 풀어 줌).

## 주소
- `/` 화면, `/ws` 웹소켓, `/health` 상태 확인, `/stats` 접속자 수(JSON)

## 서버가 보내는 메시지
`init`(내 id, 방 번호, 지금 앉아 있는 사람들) · `join` · `leave` · `emo` · `count` · `full`
