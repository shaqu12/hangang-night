# 밤 한강 돗자리

밤 한강 강변에 돗자리가 깔려 있고, **지금 접속한 사람마다 캐릭터가 하나씩** 산책로로 걸어 들어온다. 들어온 사람은 빛나는 빈 돗자리를 눌러 직접 골라 앉고, 앉은 뒤에도 다른 빈자리를 눌러 옮길 수 있다. 같은 자리를 동시에 누르면 서버에 먼저 도착한 사람이 앉고, 늦은 사람에게는 "방금 다른 분이 먼저 앉았어요"가 뜬다. 나가면 일어나서 걸어 나간다. NPC 없음, 채팅 없음, 이모지 6개(🌙 ✨ 🍜 👋 💤 ❤️)만.

- 파일: `server.js`(실시간 서버, 약 4KB) + `index.html`(화면·소리, 약 25KB). 외부 라이브러리는 `ws` 하나. AI·음원·이미지 파일 없음.
- 방: 한 방에 돗자리 30개. 차면 다음 방(여의도 01 → 반포 01 → 뚝섬 01 …), 최대 20방 600명.
- 남용 방지: IP당 동시 접속 4개, 이모지 1.2초에 1번, 자리 옮기기 0.6초에 1번, 메시지 256바이트 제한, 30초 무응답 연결 정리.

## 화면
- 하늘: 반짝이는 별, 달(달무리·무늬), 천천히 흐르는 옅은 구름, 가끔 깜박이며 지나가는 비행기, 도시 불빛이 번진 지평선.
- 건너편: 스카이라인 3겹, 남산과 N타워, 금빛 유리 빌딩, 항공 경고등, 강변북로 가로등과 차 불빛. 불빛 번짐(작게 줄였다 키운 흐린 사본을 더해 빛이 퍼져 보이게).
- 강: 도시가 물에 거꾸로 비쳐 일렁이고 번진 빛도 함께 비침, 달빛 길, 옅은 안개.
- 아치 다리: 아치 조명과 물 위 반영, 색이 천천히 바뀌는 상판 조명과 그 빛 번짐, 지하철.
- 유람선: 2층 선실 불빛·줄전구, 물결 자국과 반영.
- 돗자리: 그림자, 가장자리 박음질, 접힌 자국, 앞쪽 그늘. 빈자리는 은은하게 빛남.
- 캐릭터: 뒤에서 본 2등신. 머리 모양 5가지(짧은 머리, 긴 머리, 묶은 머리, 비니), 가로등 쪽 테두리 빛, 숨 쉬듯 살짝 흔들리는 머리. 앉으면 절반쯤은 옆에 컵라면(김), 캔, 캠핑 랜턴(바닥에 따뜻한 빛), 휴대폰 불빛 중 하나가 있음.
- 가장자리를 살짝 어둡게(비네트). 세로 화면은 돗자리 5줄×6, 가로 화면은 3줄×10으로 펴서 겹치지 않게.

## 소리
실제 녹음 3개를 섞은 `ambience.mp3`(150초, 1.8MB)를 반복 재생한다. 파일이 없으면 소리 버튼이 숨겨진다.

| 역할 | 녹음 (Pixabay 파일 이름) | 쓴 구간 | 크기 |
|---|---|---|---|
| 도시 밤 공기 | quiet-city-square-night | 470~626초 (645~690초의 큰 소리 구간은 피함) | -33 LUFS |
| 풀벌레·먼 차 소리 | night-tree-crickets-distant-traffic | 14~170초 | -36 LUFS |
| 먼 강물 | distant-river-at-night | 80~236초 | -35 LUFS |

- 편집: 60Hz 아래를 깎고 셋을 섞은 뒤, 끝 6초를 앞 6초에 등전력 크로스페이드로 겹쳐 이음새 없이 반복. 이음새 앞뒤 0.25초 단위 RMS 차이는 0.3dB 이하.
- 결과: -30.2 LUFS, 피크 -17 dBFS로 작게 시작한다. 96kbps 스테레오 mp3.
- 출처·라이선스: [Pixabay](https://pixabay.com/sound-effects/) 효과음, [Pixabay Content License](https://pixabay.com/service/license-summary/). 상업적 이용이 가능하고 출처 표기는 필요 없다. 다만 음원 파일 자체만 따로 재배포하거나 판매하는 건 금지다(이 앱의 배경음으로 쓰는 건 괜찮다).
- 코드로 합성한 소리(바람·물소리·싱잉볼)는 "작위적"이라 모두 뺐다.

## 로컬 실행
```
npm install
npm start          # http://localhost:3000
```
혼자 여러 창으로 시험할 때는 `PER_IP=50 npm start` (IP당 4개 제한을 풀어 줌).

## 주소
- `/` 화면, `/ws` 웹소켓, `/health` 상태 확인, `/stats` 접속자 수(JSON)

## 서버가 보내는 메시지
`init`(내 id, 방 번호, 지금 앉아 있는 사람들) · `join` · `leave` · `emo` · `count` · `full`
