# 밤 한강 돗자리

밤 한강 강변에 돗자리가 깔려 있고, **지금 접속한 사람마다 캐릭터가 하나씩** 산책로로 걸어 들어온다. 들어온 사람은 빛나는 빈 돗자리를 눌러 직접 골라 앉고, 앉은 뒤에도 다른 빈자리를 눌러 옮길 수 있다. 같은 자리를 동시에 누르면 서버에 먼저 도착한 사람이 앉고, 늦은 사람에게는 "방금 다른 분이 먼저 앉았어요"가 뜬다. 나가면 일어나서 걸어 나간다. NPC 없음, 채팅 없음, 아래 줄은 깔끔하게 둘로 나뉜다: 😊 마음(감정 이모지 7개 ❤️ 👍 😂 🥺 👋 ✨ 🌙)과 🧘 행동(돗자리 위 행동 8가지, 버튼을 누르면 4×2 판이 열리고 버튼 아이콘이 지금 행동으로 바뀜).

**행동(화면 아래 줄)**: 🧘 앉기 · 🛌 눕기 · 🌟 별 보기 · 🍜 라면 · 🍗 치킨 · 📸 사진 · 🙆 기지개 · 😪 꾸벅. 누르면 같은 방 모두에게 내 캐릭터가 그 자세로 보이고, 같은 버튼을 다시 누르면 앉기로 돌아온다. **닉네임**: 들어오면 '졸린수달' 같은 5자 이내 이름이 자동으로 붙어 바로 입장한다. 입장 화면에서 바꾸거나(🎲로 다시 뽑기) 그냥 들어가도 되고, 나중에 내 캐릭터를 누르면 바꿀 수 있다. 폰에 저장돼 다음에도 유지. 서버가 5자로 자르고 욕설·비하·음란어를 막는다(띄어쓰기·숫자·기호를 빼고, 1→i 같은 바꿔치기를 되돌리고, 자음만 섞어 친 건 초성으로 비교). '운영자·관리자·admin' 같은 사칭 단어도 막는다. 같은 이름은 허용. 폭죽이 터지면 불꽃 아래에 'OO님의 폭죽'이 2.8초 떴다 사라진다.

**운영자**: Render 환경 변수 `ADMIN_KEY`(8자 이상)와 같은 키로 `/?admin=키` 주소로 한 번 들어오면 폰에 저장되고 주소에서 키는 지워진다. 운영자는 왕관 달린 금색 이름표(모두에게 보임), 더 크고 금빛인 황금 폭죽('👑 운영자 OO', 1초 간격), 그리고 아래 줄의 ⛲분수·🌠유성우 버튼(바로 켜기)을 가진다. 키를 바꾸면 예전 키로 저장된 폰은 자동으로 일반 사용자로 돌아간다.

**소원 풍선(🎈)**: 한 줄 소원(15자, 비워도 됨)을 적어 띄우면 내 자리에서 풍선이 42초 동안 천천히 하늘로 올라가고 처음 9초는 소원과 닉네임이 모두에게 보인다. 욕설·음란어 소원은 글 없이 풍선만 뜬다. 15초에 하나.

**마음 보내기**: 😊 마음 판에서 이모지를 눌러 끌어다 다른 사람 캐릭터 위에 놓으면(대상 발밑에 금색 고리) 그 이모지가 날아가고, 받은 사람에게 'OO님이 마음을 보냈어요'가 뜬다. 끌지 않고 누르면 내 머리 위에 뜬다. 다른 사람 캐릭터를 누르면 마음 판이 열리며 안내가 뜬다. 1.5초에 하나.

**쉬는 시간**: 앉은 지 1분부터 방 이름 옆에 'n분째 쉬는 중'. 5·15·30분에 짧은 인사.

**운영자가 들어오면**: 알림 없이 하늘에 오로라가 천천히 일렁이고, 그동안 띄운 풍선은 금빛이 된다. 운영자 캐릭터는 금빛 오라와 둘레를 도는 반짝이, 왕관 이름표로 한눈에 다르다.

**운영자만**: 💬 말풍선으로 자유롭게 말하기(80자, 8초), 닉네임 12자·거르지 않음, 풍선 소원 40자·간격 없음, 하트 간격 없음, 황금 폭죽 1초 간격, ⛲·🌠 버튼, 

**나에게 하고 싶은 말(💌 한강 우체통)**: 산책로 가운데 빨간 우체통. 누르면 편지지가 열리고, 가까운 사람에게 못 한 말을 300자까지 적은 뒤 둘 중 하나를 고른다. 🍃 혼잣말: 종이배가 되어 강물에 내려앉아 천천히 떠내려가며 사라진다(답 없음). 💌 듣고 싶은 말: 먼저 🤗 위로 / 💪 응원 / 👏 잘했다는 말 / 👂 그냥 들어줘 중 하나를 고르면, 편지가 우체통으로 날아가 우체통이 환해진 뒤 답장이 한 글자씩 써진다. 답장 = 글의 결(지침·슬픔·불안·자존감·관계·화남·일·기쁨, 낱말로 판단)에 맞춘 공감 첫 줄 27개 + 고른 말투 본문 36개 + '지금 해 볼 것' 하나(8개, 그냥 들어줘는 조언 없이). 🔄 다른 말 듣기(같은 글로 다른 답장), 🌬️ 같이 숨 쉬기(4초 들이쉬고 6초 내쉬기 3번, 동그라미가 커졌다 작아짐). 글은 서버로 보내지 않고 폰 안에서만 다루며 어디에도 저장되지 않는다. 욕설·음란어는 폰 안에서 거르고(목록은 server.js가 페이지에 끼워 줌, 낱말마다 비교, 사정·벗어나다·한남대교 같은 일상어는 통과), "죽고 싶다" 같은 위기 표현에는 혼잣말이어도 자살예방상담 109·청소년 1388을 함께 보여 준다.

**🐶🐱 산책로 친구(간식 후원)**: 5분마다 50초 동안 강아지나 고양이 한 마리(몽이·콩이·나비·까미 중 회차마다 무작위, 시계로 정해서 모두 같은 때 같은 친구)가 산책로로 걸어와 앉아 "간식 줄래요?" 하다가 돌아간다. 누르면 창이 열리고 맨 위의 큰 🤚 쓰다듬기 버튼을 누를 때마다 하트와 반응이 바뀐다(창은 그대로). 아래쪽에 작게 "서버비에 보태고 싶다면" 1,000 / 3,000 / 5,000원 간식 주기: 폰은 카카오페이 송금 링크를 열고 PC는 폰으로 찍을 QR(qrcodejs, cdnjs)을 보여 준다. 금액은 카카오페이 화면에서 직접 넣는다(링크가 금액을 못 받음). 송금 주소는 Render 환경 변수 `DONATE_URL`(https만)이 있으면 그걸, 없으면 기본값 https://qr.kakaopay.com/Ej7ooGTO1.

**🎈 고민 풍선(함께 나누기)**: '나에게 하고 싶은 말'에서 쓴 사람이 "🎈 익명으로 함께 나누기"를 고를 때만, 이름 없이 같은 방 하늘에 보랏빛 LED 풍선으로 1분 떠 있다(120자, 3분에 한 번, 서버 메모리에만·저장/로그 없음). 다른 사람은 풍선을 눌러 🫂 안아줄게요 / 🤝 나도 그랬어요 / 💪 응원해요 / 🌙 곁에 있어요 중 하나만 보낼 수 있다(자유 댓글 없음, 고민 하나에 한 번). 공감마다 풍선이 밝아지고 조금씩 높이 오르며 10초 더 머문다(최대 2분). 쓴 사람에게는 '누군가 "안아줄게요" 하고 곁에 있어요' 알림. 욕설·음란어는 막고, 위기 표현은 나누지 않고 109·1388 안내.

**🍵 오늘의 한 줄**: 들어오고 2.5초 뒤 한국 날짜에 맞춘 다정한 문장(34개, 매일 바뀜)이 도시 위 하늘에 9초 떠올랐다 사라진다. **🌠 별똥별 신호**: 하늘을 누르면 그 자리에서 큰 별똥별이 떨어지고 같은 방 모두의 화면에도 같은 자리에 떨어지며 "방금 별똥별 봤어요? OO님이 보냈어요"(10초에 한 번, 알림은 8초에 한 번). **캐릭터 성별**: 입장 화면에서 👦 남자(짧은 머리·비니) / 👧 여자(긴 머리·묶은 머리 + 분홍 리본) / 🙂 선택 안 함(무작위). 폰에 저장(`hn-gender`), 서버는 `g`로 다른 사람에게 전달.

**📊 방문 통계(운영자)**: 아래 줄 📊 통계 버튼. 오늘(한국 날짜) 들어온 사람(IP를 하루짜리 해시로만 셈, 저장 안 함)·지금 접속·동시 최고·접속 수·평균 머문 시간·5분 넘게 머문 사람·유입(`?from=`), 지난 7일 표. 숫자는 서버가 켜진 뒤부터(무료 서버는 배포·재시작 때 0부터). 보존용으로 Render Logs에 한 시간마다 `[stats-now]`, 하루가 끝날 때 `[stats]`, 꺼지기 직전 `[stats 보관]` 한 줄. 같은 숫자는 `/stats`에서도 JSON으로 보인다.

**함께 앉은 사람 수**: 방 이름 아래에 "지금 N명이 함께 앉아 있어요"(2명 이상일 때). **단골 알아보기**: 강아지·고양이를 쓰다듬으면 이 폰(localStorage `hn-pets`)에 기억해 두고, 다음에 만나면 "몽이가 알아봤어요! 지난번에 쓰다듬어 줬죠?"

**📝 바라는 점**: 우체통 옆 게시판을 누르면 의견 창. 운영자에게 가야 하므로 서버에 보관: 메모리 + feedback.json + Render Logs `[바라는점]` 한 줄 + 배포 직전 `[바라는점 보관]` 전체 + 접속 중인 운영자 폰에 실시간 사본(localStorage `hn-letters`). 1분에 1번, IP당 하루 5번, 욕설·음란어는 돌려보냄. 운영자는 아래 줄 📝 바라는 점 버튼(개수 표시)으로 읽는다.

**운영자 글**: 💬 말하기(말풍선)와 📢 공지(모든 방 화면 위 금색 배너, 15초~2분, ✕로 닫기, 10분 안에 들어온 사람도 봄, 비워서 보내면 내림)는 길이 제한 없음(안전상 2000자, 줄바꿈 유지). 긴 말풍선은 16자씩 줄을 나눠 5줄씩 5초마다 다음 쪽으로 넘어간다. 일반 사용자 메시지는 계속 256바이트로 자른다.

**소리 끄기**: 오른쪽 위 '🔊 소리' 버튼(크게)에서 전체 끄기·크기, 강물·도시·풀벌레, 그리고 '🎆 폭죽 소리'만 따로 끄고 크기 조절. 폰에 저장.

**배포 중 끊김**: Render가 새 버전을 올릴 때 서버가 꺼지기 직전 '잠깐 새 단장 중이에요'를 보내고, 페이지는 1초 뒤부터 자동으로 다시 붙어 닉네임·앉아 있던 자리·행동을 되찾는다(그 자리를 다른 사람이 먼저 차지했으면 서서 기다림).

**유성우**: 3분마다 22초 동안 꼬리 달린 별이 1초에 1~2개 떨어진다. 시계로 정해서 접속한 모두가 같은 때 본다.

**달빛무지개분수**: 평소엔 꺼져 있다가, 누가 폭죽을 쏠 때 12% 확률로(서버가 정함, 약 8발에 1번) 상판 노즐 수백 개(2.4U 간격)가 촘촘한 물 커튼을 만들고, 빨주노초파남보 무지개색이 다리를 따라 흐르며 높낮이가 물결처럼 출렁인다. 다리 둘레 무지개 빛 번짐, 노즐 불빛, 흘러내리는 물방울, 떨어지는 자리의 물안개, 반짝이는 물보라, 강물에 일렁이는 반사가 25초 동안 이어진다. 같은 방 모두가 동시에 보고, 쇼 중간에 들어온 사람도 남은 시간만큼 본다. 끝나고 그 방은 1분 동안 다시 안 켜진다. 쇼 동안 강물 녹음을 한 겹 더 은은하게 깐다. 확률은 환경 변수 `FOUNTAIN_P`로 바꿀 수 있다(시험할 땐 1).

**폭죽(🎆)**: 버튼을 누르고 화면을 아래로 당겼다 놓으면(새총처럼 좌우로 당기면 반대쪽으로 방향이 바뀌고 점선이 목표를 보여 줌, 서버는 가로 위치를 화면 비율로 모두에게 전달) 내 캐릭터 자리에서 폭죽이 솟아 야경 위에서 터지고 강물에 비친다. 당긴 길이로 높이·크기가 정해지고, 모양(국화·고리·버들·겹꽃·하트)과 색 7가지는 서버가 무작위로 정해 같은 방 모두에게 똑같이 보인다. 한 사람당 2.5초에 1발, 화면 전체 불꽃 알갱이는 900개까지(한 발 36~80개), 소리는 올라갈 때 '슈우웅'(바람 소리에 작은 사인파 휘파람 900→2000Hz를 살짝 섞음. 기계음처럼 들린다는 의견으로 줄임), 터질 때 '펑' + 0.33초 메아리·2.6초 잔향·타다닥. 터질 때 작고 둥근 '퐁'(사인파 640→290Hz, 0.2초) + 짧은 숨소리, 버들·국화는 끝에 작은 '띵' 몇 개. 긴 메아리·저음 없음. 기본 크기에서 약 -35 LUFS(배경 강물 -48 LUFS보다 13dB 큼), 꼭대기 -16dBFS, 소리 패널 전체 크기를 따름. 오늘 쏜 수는 그 기기에 저장된다. 이모지는 맨 왼쪽 😊 마음 버튼 안에 있고, 👋를 보내면 캐릭터가 손도 흔든다. 그림은 기존 캔버스에 선 몇 개를 더 그리는 정도라 폰 부담이 거의 늘지 않는다.

- 파일: `server.js`(실시간 서버, 약 4KB) + `index.html`(화면·소리, 약 25KB). 외부 라이브러리는 `ws` 하나. AI·음원·이미지 파일 없음.
- 방: 한 방에 돗자리 30개. 차면 다음 방(여의도 01 → 반포 01 → 뚝섬 01 …), 최대 20방 600명.
- 남용 방지: IP당 동시 접속 20개(통신사·학교 와이파이는 IP를 여럿이 같이 써서 넉넉히, 환경 변수 `PER_IP`로 변경), 이모지 1.2초에 1번, 자리 옮기기 0.6초에 1번, 행동 0.4초에 1번(정해진 8가지만 통과), 메시지 256바이트 제한, 30초 무응답 연결 정리.

## 화면
- 하늘: 남색 → 보라 → 지평선의 따뜻한 자주 그라데이션, 별 210개(40개는 반짝임), 25~60초마다 별똥별, 달, 옅은 구름, 가끔 비행기.
- 건너편: 스카이라인 3겹, 남산과 N타워, 금빛 유리 빌딩, 모서리·꼭대기에 천천히 색이 도는 LED 빌딩 3채, 18~68초 주기로 하나씩 켜지고 꺼지는 창문 최대 160개, 항공 경고등, 강변북로 차 불빛. 불빛 번짐(블룸).

## 소리
실제 녹음 3개를 섞지 않고 **따로** 반복 재생한다. 오른쪽 위 🔊를 누르면 전체 크기와 강물·도시·풀벌레를 각각 켜고 끄고 크기를 고를 수 있다(설정은 그 기기에 저장). 기본은 강물만 켜짐. 파일은 켠 것만 내려받는다.

| 파일 | 녹음 (Pixabay 파일 이름) | 쓴 구간 | 파일 크기 | 기본 |
|---|---|---|---|---|
| `amb-river.mp3` | distant-river-at-night | 80~236초 | 1.2MB | 켜짐, 60 |
| `amb-city.mp3` | quiet-city-square-night | 470~626초 (645~690초의 큰 소리 구간은 피함) | 1.2MB | 꺼짐, 35 |
| `amb-crick.mp3` | night-tree-crickets-distant-traffic | 14~170초 | 1.2MB | 꺼짐, 35 |

- 편집: 60Hz 아래를 깎고 각각 -24 LUFS로 맞춘 뒤, 끝 6초를 앞 6초에 등전력 크로스페이드로 겹쳐 150초 동안 이음새 없이 반복. 64kbps 스테레오 mp3.
- 크기: Web Audio 게인으로 조절(아이폰은 audio.volume을 무시함). 슬라이더 값 v는 (v/100)²배. 기본값(전체 60 × 강물 60)이면 약 **-48 LUFS**. 일반 음악(약 -14 LUFS)보다 34dB 작다.
- 강물 다듬기: 원본 강물 녹음은 200~1500Hz가 고르게 깔린 "쏴아" 소리(14분 동안 크기 변화 0.5dB)라 폰에서 바람 "휘이익"처럼 들렸다. 800Hz 위를 잘라(800Hz 위 에너지 33% → 2%) 멀리서 웅웅 흐르는 물소리로 만들고, 8초·5초 주기로 ±2dB만 천천히 커졌다 작아지게 해 물결 느낌을 냈다. 파일 자체도 4.9dB 작게.
- 섞었을 때 별로였던 이유: 도시 녹음은 에너지의 92%가 200Hz 아래(먼 차 웅웅)라 강물 위에 겹치면 탁해지고, 풀벌레 녹음은 2.36kHz 울음이 주변보다 17dB 튀어서 셋 중 가장 귀에 걸린다. 도시·강물 녹음에는 풀벌레가 거의 없다.
- 출처·라이선스: [Pixabay](https://pixabay.com/sound-effects/) 효과음, [Pixabay Content License](https://pixabay.com/service/license-summary/). 상업적 이용이 가능하고 출처 표기는 필요 없다. 다만 음원 파일 자체만 따로 재배포하거나 판매하는 건 금지다(이 앱의 배경음으로 쓰는 건 괜찮다).
- 코드로 합성한 소리(바람·물소리·싱잉볼)는 "작위적"이라 모두 뺐다.
